How to read this

Visits and page views exclude crawlers identified by Cloudflare. The report counted {{display.crawler_views}} crawler page views separately. Visits are not unique people, and unidentified automated traffic can still be counted.

The report uses Cloudflare edge analytics for this hostname only. Counts are estimates, not raw visitor records. A daily job refreshes completed UTC days; today is not included.

Referring sites and real-user browser timings aren’t measured here. This report doesn’t add a browser tracker.
