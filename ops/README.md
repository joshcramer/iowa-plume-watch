# Hosted traffic collector

The public report reads the app's SQLite table only. The host timer owns the Cloudflare fetch. Neither application container receives the API token or a writable public ingestion route. The collector sends only bounded aggregate rows over standard input to the importer in the existing worker. The native importer rejects other hostnames, duplicate dates and open days. A failed collection does not replace the last good report. Values for the same UTC day are updated in place. All-time storage grows at most one row per day; the report shows the most recent 14 completed days.

- Deploy pending traffic migrations through the site's reviewed hosted `ntnt db` plan after taking and testing an online backup. Never run the local bootstrap on hosted data.
- Deploy web and worker on the same image. Keep the existing volume and ingress. Verify the map, `/ready`, and `/stats` before enabling the timer.
- Install the pinned NTNT binary from the released image in `$HOME/.local/state/iowa-plume-watch-stats/ntnt`. Install this release's `ops/` and `lib/traffic-paths.tnt` at the same relative paths under `$HOME/.local/state/iowa-plume-watch-stats/release/`. Keep the existing platform credential in protected host storage; the launcher reads `PLUME_TRAFFIC_CREDENTIALS` if provided, or the existing `heylarri.com` credential path. The process only sends fixed Cloudflare GET/GraphQL query calls. Do not copy the token into the site, image or timer. Production platform rollout should use a dedicated Zone Analytics Read credential.
- Install the included units to `$HOME/.config/systemd/user/`; `systemctl --user daemon-reload`, then `systemctl --user start iowa-plume-watch-traffic.service`. Inspect the service's exit status and `/stats`, then enable `iowa-plume-watch-traffic.timer` with `--now`. It runs each day at 03:20 UTC, catches up after downtime, and revisits the last 14 complete UTC dates to absorb delayed provider data.
- Disable the timer before rolling back to an older image that lacks the importer. The additive table can remain on the volume. The forecast jobs and Larri.design database are not involved.

Path series use Cloudflare's path-only dimension for an explicit public-route allowlist. Query strings, arbitrary request paths, assets, APIs, and visitor-level events do not enter the report. A day with a successful path collection but no matching page requests shows zero; a legacy day without a path collection shows a gap.
